# Portfolio Fresnel Kameni pour GitHub Pages

Cette version est configurée pour le dépôt `fresnelk.github.io` et l'adresse suivante :

`https://fresnelkameni06.github.io/fresnelk.github.io/`

## Publication

1. Envoyez le contenu complet de ce dossier dans la branche `main` du dépôt GitHub.
2. Dans `Settings`, puis `Pages`, conservez `GitHub Actions` comme source.
3. Ouvrez l'onglet `Actions` et attendez que le déploiement devienne vert.
4. Ouvrez l'adresse du portfolio.

Le formulaire de contact nécessite une API externe, car GitHub Pages ne peut pas exécuter de code serveur. La clé Resend ne doit jamais être ajoutée à ce dépôt.
